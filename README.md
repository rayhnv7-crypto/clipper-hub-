# Clipper Hub

Clipper Hub is the existing operations dashboard and workspace for clipper/content workflows.

## Project direction

Preserve the existing dashboard UI. Extend it incrementally rather than replacing it.

## Current phase

- Existing dashboard prototype
- Local browser persistence (localStorage)
- JSON backup and restore

## Roadmap

1. Establish the existing dashboard as the frontend baseline.
2. Add functional modules: Accounts, Content, Projects, Tasks, Assets.
3. Define data models and connect a database/backend.
4. Add authentication, API integrations, and automation workers.
5. Test and deploy.

## Important

Dashboard figures currently represent prototype/demo data until connected to a real data source. Browser localStorage is local to the browser/device and is not cloud synchronization.
